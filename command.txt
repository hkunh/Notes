fn calculate_wnorm(window: &[f32], fft_size: usize, hop_size: usize) -> f32 {
    // 计算窗口能量
    let window_energy: f32 = window.iter().map(|w| w * w).sum();
    
    // 计算重叠因子
    let overlap_factor = fft_size as f32 / hop_size as f32;
    
    // 正确的归一化因子计算
    1.0 / (window_energy * overlap_factor).sqrt()
}

先用 RT-DETR 快速扫描整张 4K 电池板大图（检测级）。模型会迅速框出这 60 片电池中，哪几片的哪个具体位置有疑似裂纹。

把这几个极小的高清切片送给轻量级分割网络（分割级），提取裂纹的像素级轮廓。

1. 图像采集与数字切割（数字化）流水线上的近红外相机拍下的是一整块大面板（包含72片电池片）的超高清 EL 图像。
软件拿到这张超大图后，会利用传统的图像处理算法（如边缘提取、网格线识别）找到电池片之间的缝隙，然后在内存中将这张大图“划网格”，切分成 $6 \times 12$（即72张）的小图片矩阵（Tensors）。
2. 身份绑定（解决“对应哪一片”的问题）在切割的同时，系统会为这72张小图生成携带物理绝对坐标的唯一 ID。假设这块太阳能大板扫码得到的批次号是 PNL-2026-A1。
那么切出来的第 3 行、第 5 列的电池片，在内存中的代号就会被标记为 PNL-2026-A1_R3_C5。这个 ID 会作为元数据（Metadata）一直绑定在这张图片的内存对象上。
无论它在软件里被传给哪个深度学习模型，最终都能精准溯源到物理面板的具体位置。
3. 内存截取与模型接力（如何“转”到分割）这就是“级联架构”发挥作用的核心环节：初筛队列： 这 72 张带着“身份证”的小图，被批量送入目标检测模型（如 YOLO）。
结果拦截： 检测模型全速跑完，输出结果。假设系统发现除了 R3_C5 和 R6_C1 输出了含有缺陷的边界框（Bounding Box）外，其余 70 片全都是正常的。
内存复制（Crop）： 核心调度程序（通常是 C++ 或 Python 后台）会拿到这两个缺陷框的坐标。
它会直接从内存中，把 R3_C5 和 R6_C1 这两张图片对应区域的像素矩阵**复制（Crop）**出来，放进一个叫做“疑似缺陷池”的内存队列里。
激活分割： 语义分割模型被唤醒。它从“疑似缺陷池”中取出这两个局部像素矩阵进行高精度的像素级推理，计算出具体的受损面积，并将结果与它们的 ID 记录进最终的质检数据库。

并在该设置下构建 RT-DETRv2-R50vd strong baseline。所有消融实验均采用相同的输入尺寸、训练轮数、优化器、数据增强和测试流程，
因此可以公平反映 TSA、DMCFE_v2 和 LAQR 等模块相对于同一基线模型的性能贡献。

考虑到 RGBTDronePerson 数据集原始图像分辨率为 640×512，且已有 RGBTDronePerson 方法通常采用 640×512 输入协议进行训练与评估，
本文进一步在 640×512 keep-ratio 设置下训练并评估 baseline 与最终模型。该实验主要用于与现有方法进行协议对齐的性能比较，
而 640×640 设置下的实验主要用于分析各模块在 RT-DETRv2 strong baseline 上的相对增益。

此外，为分析输入尺寸对模型性能的影响，本文分别在 640×640 和 640×512 keep-ratio 两种输入设置下比较 baseline 与最终模型。实验结果表明，不同输入尺寸会影响模型的绝对检测精度，
但本文方法在相同输入协议下相对于对应 baseline 仍保持性能优势。
因此，本文后续消融分析主要关注同一设置下的相对增益，而与现有方法比较时采用 640×512 协议对齐结果
